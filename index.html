사내 고충·제안 접수→

사내에서 해결할 수 있는 고충과 제안은 이곳으로 접수해 주세요. 서진캠 고충처리 담당자가 주 2회 이상 접수 내용을 확인하고, 접수일로부터 10일 이내에 처리결과를 회신합니다. 로그인 없이 이름을 쓰지 않고도 작성할 수 있으며, 회신을 원하면 연락처를 남겨 주세요. 익명 접수는 분기별 처리현황 공지로 안내합니다.

SECO 사이버감사실 제보→

서진캠 내부에서 해결이 어렵다고 판단될 때 이용해 주세요. 서진캠이 아닌 SECO 서울사무소로 바로 접수됩니다. 예를 들어 사내 처리 결과에 동의하기 어렵거나, 문제의 당사자가 관리자 또는 고충처리 담당자인 경우입니다.

처리 절차

  1. 접수네이버폼으로 언제든 접수할 수 있습니다
  2. 접수 확인사내 고충처리 담당자만 주 2회 이상 접수 내용을 확인합니다
  3. 검토·조치사실을 확인하고 필요한 조치를 결정합니다. 담당자가 처리하기 어려운 사항은 노사협의회에 부쳐 협의합니다
  4. 회신접수일로부터 10일 이내에 조치 사항과 처리결과를 알려 드립니다
  5. 재검토 요청사내에서 해결되지 않으면 SECO 사이버감사실에 제보할 수 있습니다
